# Islands Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** The Islands look of `docs/superpowers/specs/2026-09-24-islands-design.md`.

**Architecture:** Two new theme tokens and style rules (`gui/theme.py`); `ToolWindows` restructured into islands with a full-width bottom panel (`gui/toolwindows.py`); the editor area wrapped in an island.

**Tech Stack:** PySide6 style sheets, pytest-qt (offscreen).

### Task 1: Tests first

`tests/test_gui_layout.py`:
- `test_the_bottom_panel_spans_the_full_width`: open Components, Properties and Messages; the Messages widget's global left ≤ Components' left and its right ≥ Properties' right.
- `test_frame_and_islands_have_their_own_colours` (parametrized light/dark): set `appearance/ui_theme`; grab the window; the pixel in the middle of the left stripe is the `frame` token, the pixel in an empty part of the Components panel is the `island` token.

Run: both fail (no tokens; bottom under the editor only).

### Task 2: Theme

`TOKENS` gain `frame` and `island`. In `STYLE`: `QMainWindow`, `QToolBar`, `QStatusBar` (no top border), the stripes and `QSplitter::handle` use `frame`; `QWidget#island` (radius 10 px) and everything drawn inside islands (trees, tables, lists, header sections, the property editor's body, `dock-title`, `QTabBar`) use `island`. Tabs: rounded pill for the selected one, no underline. Stripe buttons: `:checked` pill.

### Task 3: Tool windows

- `_Host` is an island: object name `island`, styled background, 4 px margins (header 10 px from the left edge, `HEADER_HEIGHT` tall).
- `ToolWindows.__init__`: `self.columns` (horizontal: left side, editor island, right host) inside `self.center` (vertical: columns, bottom host); handles 5 px; the editor wrapped in an island; content margins 0/0/0/5. `self._splitters` keeps the keys `main` (= columns), `left`, `center`.

Run the new tests and the suite; screenshots in both themes; compare with the reference; commit.
