# mems: the bundled MEMS library

Every project can use it as `mems.` without declaring a path: components such
as `mems.comb_drive` and the process `mems.surface`. Its components are in
category folders (`components/springs/...`); the folder is only where a
component is shown, its name is the same in every folder.

The processes are **examples** with typical, round values, not any foundry's
rules.
